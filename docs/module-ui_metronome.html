ui/metronome

Metronome interface (2.11; pared-down layout 2.13), reachable from every screen.

  • The ♩ button of each screen header (metroButton) opens a full-height sheet over the current screen. It is an overlay, not a screen: Android's back button closes it and the screen under it is left as it was (openOverlay).
  • The sheet shows only what is used every time; everything else is in sub-pages (time signature, subdivision, sound, jazz, options, presets), each opened from a row that shows its current value. A sub-page has its own history entry: Android's back button returns to the main page.
  • Collapsed while playing, the metronome becomes a mini-bar at the bottom of every screen (above an open palette): beat lights, tempo − +, stop, expand. Its height is reserved (--metro-h) so it never hides content.
┌ ⌄  Metronome                 ★ ┐
│   ▆ ▂ ▂ ▂                      │  bars = lights; tap: on/off, slide: level
│  (TAP)     ♩ = 120      [−][+] │  tap the number too; drag it up/down
│             Allegro            │  − + : hold for steps of 5
│  Time signature   7/8 2+2+3  › │
│  Subdivision      none       › │
│  Sound            Click      › │
│  Jazz             off        › │
│  Options                     › │
│        [  ▶  Start  ]          │  stuck to the bottom

TAP is small and outlined, away from the wide filled Start button, so the two are never confused.

Settings are remembered (meta.metro), as are the presets (meta.metroPresets). What to play is computed by metronome, played by metro-engine.

While playing and visible, the lights follow the audio clock; the vibration and flash options fire on audible beats; the "keep the screen on" option holds a Wake Lock.
