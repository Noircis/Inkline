chord-keys

Clavier d'accords (2.8.5) : ce que fait chaque touche. Fonctions pures, l'interface est dans ui/chord-keyboard.

On saisit un accord en deux temps : la fondamentale (C … B, puis ♭ ou ♯), puis la couleur d'un seul toucher (7, −7, Δ7, ø7…). Le pavé détaillé (⋯) ajoute les morceaux un par un pour les accords rares (C7♯9♭13).

Les accords sont enregistrés en texte dans la notation d'iReal Pro (-7, ^7, h7, o7), que le reste de l'appli lit déjà (chords, ireal) ; l'affichage les met en forme (C−7, CΔ7, Cø7, C°7).

Une mesure de grille est une liste de cases (ch) ; on écrit toujours dans la dernière case. ␣ en ouvre une nouvelle (deux accords dans la mesure), ⌫ efface le dernier morceau tapé.

Example
applyChordKey([], { t: 'root', v: 'B' })          // ['B']
applyChordKey(['B'], { t: 'acc', v: 'b' })        // ['Bb']
applyChordKey(['Bb'], { t: 'qual', v: '-7' })     // ['Bb-7']
applyChordKey(['Bb-7'], { t: 'space' })           // ['Bb-7', '']
applyChordKey(['Bb-7', ''], { t: 'root', v: 'E' }) // ['Bb-7', 'E']
