pdf

Générateur de PDF minimal, écrit à la main, sans bibliothèque.

Chaque page contient une seule image JPEG pleine largeur. C'est tout ce dont l'export a besoin : la note est déjà dessinée en image par export. Le texte n'est pas sélectionnable, mais le fichier fait ~30 lignes de code au lieu d'une dépendance de 300 Ko.

Structure d'un PDF

Un PDF est un fichier texte (avec des blocs binaires) composé d'objets numérotés qui se référencent (3 0 R = « l'objet n° 3 ») :

%PDF-1.4
1 0 obj << /Type /Catalog /Pages 2 0 R >> endobj      racine
2 0 obj << /Type /Pages /Kids [...] /Count n >> endobj liste des pages
pour chaque page :
  << /Type /Page /MediaBox [...] /Resources << /XObject << /Im0 … >> >> /Contents … >>
  flux de contenu : « q a 0 0 d e f cm /Im0 Do Q »  (place et dessine l'image)
  image : << /Subtype /Image /Filter /DCTDecode … >> stream <octets JPEG> endstream
xref        table des positions (en octets) de chaque objet
trailer     << /Size … /Root 1 0 R >>  puis startxref <position de xref>

Le filtre DCTDecode signifie « ce flux est un JPEG » : on recopie les octets produits par le navigateur sans aucun décodage. C'est ce qui rend ce générateur si court.

L'origine des coordonnées PDF est en bas à gauche, en points (1/72 de pouce) ; une page A4 mesure 595.28 × 841.89 points.
