model

Modèle de données d'Inkline : types (sous forme de @typedef JSDoc), constantes de durée et fabriques d'objets.

Vue d'ensemble

notes : { [id]: Note }
Note  = { id, title, created, updated, blocks: Block[] }
Block = TextBlock | StaffBlock | GridBlock     (union discriminée par `type`)

Toutes les structures sont des objets JSON simples : elles sont sérialisées telles quelles dans localStorage et dans les fichiers de sauvegarde. Les champs optionnels sont absents plutôt que false/null, ce qui garde le JSON compact (un morceau de plusieurs centaines de notes reste léger).

Unités de temps

Toutes les durées sont exprimées en noires (quarter notes) : ronde = 4, blanche = 2, noire = 1, croche = 0.5, double croche = 0.25. Une note pointée vaut ×1.5, une note de triolet ×2/3.

Hauteur

La hauteur d'une note est stockée comme position sur la portée (s, en demi-interlignes, 0 = première ligne du bas) et non comme numéro MIDI : c'est ce que l'utilisateur touche à l'écran. La hauteur réelle est calculée à la demande par pitch.
