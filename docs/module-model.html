model

Inkline's data model: types (as JSDoc @typedefs), duration constants and object factories.

Overview

notes : { [id]: Note }
Note  = { id, title, created, updated, blocks: Block[] }
Block = TextBlock | StaffBlock | GridBlock     (union discriminated by `type`)

Every structure is a plain JSON object: they are serialized as is in storage and in backup files. Optional fields are absent rather than false/null, which keeps the JSON compact (a piece of several hundred notes stays light).

Time units

Every duration is expressed in quarter notes: whole = 4, half = 2, quarter = 1, eighth = 0.5, sixteenth = 0.25. A dotted note is worth ×1.5, a triplet note ×2/3.

Pitch

A note's pitch is stored as a position on the staff (s, in half staff-spaces, 0 = bottom line) and not as a MIDI number: that is what the user taps on screen. The actual pitch is computed on demand by pitch.
