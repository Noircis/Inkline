export

Partage d'une note : fichier .inkline, image PNG ou PDF.

Rendu d'une note en image

  1. noteToSvg compose la note entière dans un seul SVG : titre, date, blocs texte (retour à la ligne calculé avec CanvasRenderingContext2D.measureText), portées (module:render-staff), grilles (gridSvg). Toujours en thème clair, pour l'impression.
  2. Les polices sont embarquées dans le SVG en base64 (data: URI) : une image SVG affichée par <img> n'a pas le droit de charger des fichiers externes. On relit css/fonts.css pour savoir lesquelles.
  3. Le SVG est chargé dans un Image, dessiné sur un <canvas> à ×2 (netteté sur écran haute densité), puis exporté en PNG ou en JPEG.
  4. Pour le PDF, l'image est découpée en pages A4, de préférence entre deux blocs, puis assemblée par buildPdf.

Envoi

shareOrDownload ouvre le menu de partage d'Android (API Web Share) quand le navigateur l'accepte pour ce type de fichier, et télécharge le fichier sinon.

Description:

  • Ouvre le menu de partage du téléphone avec le fichier, ou le télécharge.

    Chrome Android n'accepte de partager que certains types (images, PDF, texte…). Un .inkline (JSON) n'en fait pas partie : on tente donc plusieurs variantes de nom/type, du plus propre au plus compatible, puis on se replie sur le téléchargement.
