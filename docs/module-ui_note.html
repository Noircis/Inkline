ui/note

Écran note : titre, rangement (dossier, épingle), blocs, barre d'ajout, partage, suppression.

Le rendu est fait par template strings et innerHTML, puis les gestionnaires d'événements sont branchés sur les éléments créés. Les blocs texte sont gérés ici ; les blocs portée et grille sont délégués, via le registre de ui/blocks, à ui/staff-ui et ui/grid-ui.
