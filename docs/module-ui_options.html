ui/options

Écran Options, ouvert par la roue crantée de l'accueil.

Il regroupe ce qui concerne le carnet entier, pour garder l'accueil dédié aux notes :

  • Affichage : Cartes, Mosaïque ou Liste pour l'accueil ;
  • Carnet : exporter une sauvegarde complète, importer un fichier (sauvegarde ou note reçue .inkline), date de la dernière sauvegarde ;
  • iReal Pro : importer un lien, une playlist ou un fichier .html ;
  • À propos : version, nouveautés, documentation du code.

Rappel de sauvegarde

Les notes ne vivent que sur le téléphone. Au-delà de BACKUP_REMINDER_DAYS jours sans export, un point apparaît sur la roue crantée (backupDue) : c'est un rappel visible, mais jamais bloquant.
