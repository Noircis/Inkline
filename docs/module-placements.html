placements

Entraînement rythmique : placements (depuis la 2.3). Fonctions pures.

Une mesure de 4/4 contient 8 croches, donc 8 positions (0 à 7) :

position : 0  1  2  3  4  5  6  7
compte   : 1  et 2  et 3  et 4  et

Pour n notes, on génère toutes les façons de choisir n positions parmi 8 (combinations) : 8 pour une note, 28 pour deux, 56 pour trois, 70 pour quatre… puis on écrit chaque placement selon les règles d'usage (placementItems), et on les regroupe en séries (groupSeries).

Règles d'écriture (croches)

Temps par temps :

sur le temps contretemps écriture
note rien noire
rien note demi-soupir + croche
note note deux croches (ligaturées)
rien rien soupir

Une note ne déborde jamais sur le temps suivant (pas de syncope). Puis les silences sont regroupés : deux soupirs sur les temps 1-2 ou 3-4 deviennent une demi-pause. Jamais sur 2-3 : en 4/4, le milieu de la mesure doit rester visible.

Description:

  • Toutes les façons de choisir k positions parmi n, dans l'ordre lexicographique : [0,1], [0,2]… Algorithme récursif classique : pour chaque première position possible, on complète avec les combinaisons des positions suivantes.

(static) groupSeries(placements) → {Array.<Array.<Array.<number>>>}

Description:

  • Regroupe des placements en séries : une série réunit les placements dont la première note est à la même position (ils sont déjà consécutifs dans l'ordre de combinations). Cas particulier : avec une seule note, chaque placement serait seul dans sa série ; on les réunit tous en une seule.
