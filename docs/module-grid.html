grid

Pure logic of chord charts (iReal Pro style): input, durations, playback order, HTML rendering (screen) and SVG rendering (image export). Interaction (palette, taps) is in ui/grid-ui.

Rendering

The chart is a 4-column CSS Grid: one measure per cell, 4 measures per line as in iReal. Barlines are not drawn: they are the cells' borders, chosen through CSS classes from the flags of the measure and of its left neighbor:

Class Meaning
lb-rs left border = start repeat ‖:
lb-dbl left border = double barline (section start)
lb-none no left border (the neighbor already has a special barline)
rb-re right border = end repeat :‖
rb-dbl right border = double barline
rb-fin right border = final barline
rb simple right border (end of line)

(static) gridPlayOrder(M) → {Array.<number>}

Description:

  • Playback order of the measures, with repeats and endings.

    State machine with three variables:

    • rsI: index of the last start repeat (0 by default);
    • pass: 1st or 2nd pass through the current repeat;
    • jumped: end repeats already taken.

    Transitions:

    • a new rs measure (other than the one just jumped to) opens a repeat: pass = 1;
    • on the 2nd pass, a measure starting the 1st ending jumps straight to the 2nd ending;
    • an end repeat not yet taken goes back to rsI with pass = 2;
    • a final barline stops playback.

(static) gridSvg(b, W) → {Object}

Description:

  • SVG rendering of a chart, for image or PDF export.

    Same logic as gridHtml, but barlines are real strokes (not CSS borders) and chords are <text> elements: the result is self-contained and can be rasterized.

    Layout: 4 measures per line, cells W / 4 wide. Section and ending marks overflow above each line, hence the space reserved at the top.

(static) gridTokens(txt) → {Array.<string>}

Description:

  • Turns a measure's input into slots.

    • separators: spaces and commas;
    • / → empty slot (continues the previous chord);
    • n, NC, N.C. → no chord;
    • % → measure repeat;
    • the first letter is capitalized (bb7 → Bb7), handy on a phone keyboard.

(static) slotDurations(k, time) → {Array.<number>}

Description:

  • Duration (in quarter notes) of each of the k slots of a measure.

    The measure's beats are spread over the slots, the first ones getting the surplus, as in iReal:

    • 4/4, 2 chords → 2 + 2; 3 chords → 2 + 1 + 1; 4 chords → 1 each;
    • 3/4, 2 chords → 2 + 1. In compound time (x/8), the beat is the dotted quarter note.
