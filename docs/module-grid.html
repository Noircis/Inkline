grid

Logique pure des grilles d'accords (façon iReal Pro) : saisie, durées, ordre de lecture, rendu HTML (écran) et SVG (export en image). L'interaction (palette, clics) est dans ui/grid-ui.

Rendu

La grille est une CSS Grid de 4 colonnes : une mesure par cellule, 4 mesures par ligne comme dans iReal. Les barres de mesure ne sont pas dessinées : ce sont les bordures des cellules, choisies par classes CSS selon les drapeaux de la mesure et de sa voisine de gauche :

Classe Signification
lb-rs bord gauche = début de reprise ‖:
lb-dbl bord gauche = double barre (début de section)
lb-none pas de bord gauche (la voisine a déjà une barre spéciale)
rb-re bord droit = fin de reprise :‖
rb-dbl bord droit = double barre
rb-fin bord droit = barre de fin
rb bord droit simple (fin de ligne)

(static) gridPlayOrder(M) → {Array.<number>}

Description:

  • Ordre de lecture des mesures, avec reprises et voltas.

    Automate à trois variables :

    • rsI : index du dernier début de reprise (0 par défaut) ;
    • pass : 1er ou 2e passage dans la reprise courante ;
    • jumped : fins de reprise déjà prises.

    Transitions :

    • une nouvelle mesure rs (autre que celle où l'on vient de sauter) ouvre une reprise : pass = 1 ;
    • au 2e passage, une mesure qui commence la 1re fin fait sauter directement à la 2e fin ;
    • une fin de reprise non encore prise renvoie à rsI avec pass = 2 ;
    • une barre de fin arrête la lecture.

(static) gridSvg(b, W) → {Object}

Description:

  • Rendu SVG d'une grille, pour l'export en image ou en PDF.

    Même logique que gridHtml, mais les barres sont de vrais traits (pas des bordures CSS) et les accords des <text> : le résultat est autonome et peut être rasterisé.

    Mise en page : 4 mesures par ligne, cellules de W / 4 de large. Les repères de section et de volta débordent au-dessus de chaque ligne, d'où l'espace réservé en haut.

(static) gridTokens(txt) → {Array.<string>}

Description:

  • Transforme la saisie d'une mesure en cases.

    • séparateurs : espaces et virgules ;
    • / → case vide (prolonge l'accord précédent) ;
    • n, NC, N.C. → no chord ;
    • % → répétition de la mesure ;
    • la première lettre est mise en majuscule (bb7 → Bb7), pratique au clavier du téléphone.

(static) slotDurations(k, time) → {Array.<number>}

Description:

  • Durée (en noires) de chacune des k cases d'une mesure.

    On répartit les temps de la mesure entre les cases, les premières recevant le surplus, comme iReal :

    • 4/4, 2 accords → 2 + 2 ; 3 accords → 2 + 1 + 1 ; 4 accords → 1 chacun ;
    • 3/4, 2 accords → 2 + 1. En mesure composée (x/8), le temps est la noire pointée.
