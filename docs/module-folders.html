folders

Dossiers du carnet (depuis la 2.0) : modèle et opérations pures.

Modèle

Un dossier est un objet { id, name, color, created }. Les dossiers sont stockés à part des notes (voir storage) ; une note référence son dossier par son id dans le champ optionnel folder. Une note sans folder (ou dont le dossier n'existe plus) est « non classée ».

Un seul niveau : pas de sous-dossiers. C'est un choix de simplicité pour un usage au téléphone (un dossier par cours, par projet…).

Vues spéciales

La barre de dossiers de l'accueil propose deux entrées qui ne sont pas des dossiers : ALL (toutes les notes) et UNFILED (notes non classées).
