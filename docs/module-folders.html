folders

Notebook folders (since 2.0): model and pure operations.

Model

A folder is an object { id, name, color, created }. Folders are stored separately from notes (see storage); a note references its folder by id in the optional folder field. A note without folder (or whose folder no longer exists) is "unfiled".

No subfolders, but categories (2.8.6): each folder has its own ordered list of categories (cats, for example Technique, Sound, Improv in "Saxophone"). A note can have several (the note's cats field, ids of its folder's categories); it then appears in each section (groupByCategory). Moving a note to another folder clears its categories: they only make sense in their folder.

Special views

The home folder bar offers two entries that are not folders: ALL (all notes) and UNFILED (unfiled notes).
