ui/grid-ui

Interaction with a chord chart block:

  • header (key, time signature, style, tempo, iReal, playback);
  • iReal Pro panel: open/copy the link, import a link or a file;
  • selecting a measure by tapping;
  • palette: chord input field, structure marks, navigation.

Fast input

The field updates the measure on every keystroke (live preview). Enter (or ↵) confirms and moves to the next measure, creating one if needed. The | character fills several measures at once; it is interpreted only on confirmation, so that no measures are created while typing.
