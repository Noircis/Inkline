ui/staff-ui

Interaction avec un bloc portée (ou ligne rythmique) :

  • en-tête du bloc (clé, mesure, tempo, swing, lecture) ;
  • toucher sur la portée (staffTap) : ajout, sélection, déplacement d'une note ;
  • palette fixée en bas d'écran : valeurs, point, triolet, silence, liaison, altérations, barres, accord chiffré, navigation, annuler, effacer.

Deux modes pour chaque bouton de la palette

  • Une note est sélectionnée : le bouton modifie cette note.
  • Aucune sélection : le bouton règle la prochaine note ajoutée (voir InputSettings).

Toute modification est précédée de pushSnapshot (pour pouvoir annuler) et suivie de touch (sauvegarde) puis d'un redessin du bloc.

(static) staffTap(n, b, e)

Description:

  • Gère un toucher sur la portée.

    1. Active le bloc s'il ne l'était pas (et ferme le clavier éventuel).
    2. Refait la mise en page avec la même largeur que le rendu, puis convertit les coordonnées : ligne = floor(y / hauteurDeLigne), élément = celui dont l'intervalle [x0, x1) contient x, hauteur = stepFromY.
    3. Selon la cible :
      • un élément déjà sélectionné : déplace la note à la hauteur touchée ;
      • un autre élément : le sélectionne ;
      • la zone d'ajout (après la dernière note) : ajoute une note avec les réglages de saisie ;
      • ailleurs : désélectionne.

(inner) toggleTie()

Description:

  • Bascule la liaison sur la note sélectionnée. Si la note suivante existe, elle prend la même hauteur (une liaison de prolongation relie deux notes identiques) et perd son altération (la hauteur est portée par la liaison). Sans sélection : la prochaine note ajoutée sera liée à la dernière.
