rhythm

Everything about time on a staff, independent of drawing:

  • splitting into measures (segmentMeasures),
  • grouping triplets (tupletGroups),
  • grouping beams (beamGroups),
  • playback order with repeats (staffPlayOrder),
  • swing (swingWarp),
  • computing the list of sound events (staffEvents).

These functions are pure (no DOM, no side effects): the layout engine, the SVG renderer and the audio player all rely on them, which guarantees they agree with each other. They are covered by tests/rhythm.test.js.

(static) beamGroups(items, time, meteropt) → {Array.<Array.<number>>}

Description:

  • Groups the eighth and sixteenth notes to be joined by a beam.

    Rules:

    • only notes (not rests) of eighth or sixteenth value are beamed;
    • a group does not exceed one beat (a quarter in x/4, a dotted quarter in x/8);
    • a group crosses neither a barline nor a triplet boundary (a triplet of eighths forms its own beam);
    • a single-item group is not a beam (the note keeps its flag).

    Splitting by line (system) is not done here: it depends on the layout and is applied by the renderer.

(static) segmentMeasures(items, time) → {Array.<Measure>}

Description:

  • Splits a sequence of items into measures.

    Rules, in order:

    1. an item marked rs (start repeat) always opens a new measure; the current measure is closed by a single barline;
    2. an item carrying a barline (bar) closes the measure even if it is incomplete: this is what allows ending a pattern anywhere;
    3. otherwise the measure closes when the sum of durations reaches its capacity.

    The last measure may stay open (full: false): that is where the user adds the next notes.

(static) staffEvents(b) → {Object}

Description:

  • Builds the list of sound events of a staff.

    Steps:

    1. playback order with repeats (staffPlayOrder);
    2. positions in quarter notes by summing the actual durations (triplets included);
    3. ties: if the previous item in playback order is the note right before in the score and it is tied, its end is extended instead of triggering a new note;
    4. swing: swingWarp is applied beat by beat, only to beats written in eighths (straightBeats): a beat containing sixteenths (or a dot falling on a quarter of a beat) is played straight. Triplet notes are never warped (already ternary). Swing is not applied in compound time (x/8).

(static) staffPlayOrder(items) → {Array.<number>}

Description:

  • Playback order of items, repeats unrolled.

    Items are walked through while remembering the last start repeat rs. On reaching an end repeat (bar: 'rep') for the first time, playback goes back to the start repeat; the second time it continues. The done set remembers the end repeats already taken.

    A guard of 4000 items prevents any infinite loop on inconsistent data.

(static) staffSegment(b, from, to) → (nullable) {Object}

Description:

  • A part of a staff's playback (2.8.4): from measure from to measure to (written index, from 0).

    Unrolled playback (repeats included) goes through a sequence of measures, some of them several times. The segment starts at the first pass through from and stops at the first pass through to that follows (a repeat contained in the segment is therefore played unrolled). Times are shifted to the start of the segment.

    A tied note arriving from before the segment is attacked (otherwise the segment would start with silence).

(static) swingWarp(q) → {number}

Description:

  • Swing time warp (triplet-feel eighths).

    Within each beat (fractional part r of the position in quarter notes), the first half is stretched to 2/3 and the second compressed to 1/3: the offbeat eighth falls at 2/3 of the beat, like a triplet eighth.

    r:   0 ──── 0.5 ──── 1
w:   0 ──── 0.667 ── 1

    The function is continuous and monotonic: event order is preserved.

(static) tupletGroups(items, time) → {Array.<TupletGroup>}

Description:

  • Groups consecutive triplet items into triplets.

    Rule for closing a group

    A triplet is 3 times the smallest value of the group, played in the time of 2. So the smallest written duration min met so far and the written sum written are tracked; the group is complete when written ≥ 3 × min.

    This covers the usual cases:

    • eighth-eighth-eighth: min = ½, 3 × ½ = 1.5 = sum → complete (lasts 1 quarter)
    • quarter-eighth: min = ½, 1 + ½ = 1.5 → complete (lasts 1 quarter)
    • quarter-quarter-quarter: min = 1 → complete on 3 (lasts 2 quarters)

    A group is also cut, even incomplete, by an item without tup or by a barline.

(inner) straightBeats(items, order) → {Set.<number>}

Description:

  • Beats to play straight despite swing: those where a note (outside a triplet) starts or ends somewhere other than on the beat or on the offbeat eighth.

    Why: swingWarp is meant for eighth notes. Applied to sixteenths, it made them uneven (1/3, 1/3, 1/6, 1/6 of the beat instead of four equal quarters). In jazz, a sixteenth-note passage in a swing tune is played straight (as in "double time"): only beats written in eighths are swung.
