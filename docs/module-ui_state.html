ui/state

État de l'interface, partagé par tous les modules ui/*.

L'app suit un modèle immediate mode : il n'y a pas de framework réactif. Un module modifie state (ou une note), puis demande explicitement le re-rendu de ce qui a changé (renderNote, redrawStaff, redrawGrid).

Toutes les variables d'état sont regroupées ici plutôt qu'éparpillées en variables globales : on sait ainsi ce qui existe et qui le modifie.
